# Iconography reference

**Library:** Lucide React (`lucide-react`) — used throughout Open Brain, substituted here for Cloudscape's in-house SVG set.

**Stroke:** 2px, 24px grid, round line caps and joins.

## Key mappings (Open Brain usage → Cloudscape equivalent → Lucide name)

| Open Brain use | Cloudscape `<Icon name>` | Lucide |
|---|---|---|
| Dashboard nav | `multiscreen` | `LayoutDashboard` |
| Search | `search` | `Search` |
| Timeline / activity | `clock` | `Clock` |
| Upload / ingest | `upload` | `Upload` |
| Entities (people) | `user-profile` | `Users` |
| Wiki / docs | `file` | `BookOpenText` |
| Briefs | `file` | `FileText` |
| Board / governance | `gen-ai` | `Gavel` |
| Intelligence | `status-positive` | `Lightbulb` |
| Voice capture | `microphone` | `Mic` |
| Email | `envelope` | `Mail` |
| Financial | `caret-up-filled` | `DollarSign` |
| Investments | `insert-chart` | `LineChart` |
| System status | `settings` | `Monitor` |
| Settings | `settings` | `Settings` |
| Help | `status-info` | `HelpCircle` |
| Refresh | `refresh` | `RefreshCw` |
| Add / capture | `add-plus` | `Plus` |
| Alert / error | `status-negative` | `AlertCircle` |
| Filter | `filter` | `Filter` |
| Notification | `notification` | `Bell` |
